Narrow vs broad IPA

Broad IPA, written between slashes, records which sound was meant. Narrow IPA, written in square brackets, records exactly how it was made: aspiration, ejectives, clicks, trills.

Vocal percussion lives in the details, so this atlas uses narrow IPA throughout.
